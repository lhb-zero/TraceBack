## 问题现象

升级 LangChain 从 0.1.x 到 0.2.x 后，项目启动直接报错：
```
ImportError: cannot import name 'ConversationBufferMemory' from 'langchain.memory'
```
所有用到 Memory 的 chain 全部崩溃。

## 环境

- Python: 3.11
- LangChain: 0.1.16 → 0.2.5
- langchain-community: 未安装（0.2 后拆分了）

## 排查过程

1. 查 changelog → 发现 0.2 大版本把 memory 模块整体迁移到了 `langchain-memory` 独立包
2. 安装 `langchain-memory` 后 import 路径变了
3. 进一步发现 `ConversationChain` 也被标记为 deprecated，推荐用 LCEL

## 根因

LangChain 0.2 是一次破坏性重构：
- memory 相关类移到独立包 `langchain-memory`
- 旧的 `ConversationChain` 被废弃
- 很多 import 路径从 `langchain.xxx` 变为 `langchain_community.xxx` 或 `langchain_core.xxx`

## 解决方案

最终决定不升级，锁定版本：
```txt
langchain==0.1.16
langchain-community==0.0.38
```

同时写了一个迁移检查脚本，列出所有需要修改的 import：
```bash
grep -r "from langchain.memory" src/
grep -r "from langchain.chains" src/
```

等后续有时间再整体迁移到 LCEL 架构。

## 预防/备忘

- LangChain 大版本升级一定是破坏性的，永远不要 `pip install --upgrade langchain` 不锁版本
- 生产项目 requirements.txt 必须锁死版本号（用 `==` 而非 `>=`）
- 升级前先看 migration guide：https://python.langchain.com/docs/changelog/
- 考虑用 `pip-compile` 或 `poetry.lock` 锁定完整依赖树
