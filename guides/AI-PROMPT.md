# AI 复盘生成 Prompt

## 使用方法

1. 复制下方 **[Prompt 正文]** 部分
2. 在 **[项目信息]** 部分填入你的项目情况（能填多少填多少）
3. 一起发送给任意 AI（ChatGPT / Claude / Gemini / 本地模型均可）
4. 将 AI 输出粘贴到对应的 `.mdx` 文件中
5. 补充只有你自己才知道的感受（选填）

> 注意：AI 无法替你写"我学到了什么"中的真实感受，这部分建议自己补充。

---

## Prompt 正文

```
你是一个项目复盘助手。你的任务是根据我提供的项目信息，生成一份结构化的项目复盘文档。

## 输出格式要求

严格按照以下 MDX 格式输出（包括 frontmatter 和正文）：

### Frontmatter（YAML 格式）：
---
title: "项目名称"
date: YYYY-MM-DD
period: "起始 ~ 结束"
status: ongoing | completed | abandoned
tags: [标签1, 标签2, ...]
template_version: 1
summary: "一句话总结"
highlight: "最大收获"
understanding_score: 1-5
review_after: YYYY-MM-DD 或 null
repo: "GitHub 仓库 URL" 或 ""
commits:
  - hash: "短hash"
    note: "说明"
prs: []
sub_docs: []
---

### 正文结构（五个二级标题）：

## 项目概述
（做了什么、为什么做、最终效果/状态）

## 技术要点
（技术选型理由、架构设计思路、核心技术难点及解法）

## AI 协作记录
（AI 做了哪些部分、你修改了什么、理解验证、Prompt 经验）

## 踩坑与解决
（过程中遇到的主要问题及解决方式）

## 我学到了什么
（用自己的话总结真正内化的知识和技能）

## 约束规则

1. 全部使用中文输出
2. 信息不足的部分标注 [信息不足]，不要编造
3. 不要写空话套话，每句话要有具体信息量
4. 技术描述要具体到工具名、版本号、具体做法
5. AI 协作部分要具体到"AI 生成了什么 → 我改了什么 → 为什么改"
6. "我学到了什么"部分用第一人称，语气自然，像写给自己的笔记
7. 如果项目信息中有 commit hash 或 PR 链接，填入 frontmatter 对应字段

---

## 项目信息

- 项目名称：
- 时间周期：
- 项目状态（进行中/已完成/已废弃）：
- GitHub 仓库地址（如有）：
- 项目简述（做什么、给谁用）：
- 技术栈：
- 关键 commit 或 PR（如有）：
- 遇到的主要困难：
- AI 辅助了哪些部分：
- 你个人最大的收获（可选，AI 无法替你写这个）：
```

---

## 补充说明

- 如果项目有多个阶段，可以分多次生成，每次生成一个里程碑记录（使用 `log.mdx` 模板格式）
- 如果 AI 协作内容很丰富，可以单独生成 `ai-collaboration.mdx`
- 如果有重要的技术决策，可以单独生成 `decisions.mdx`
- 生成后记得更新 `index.mdx` 中的 `sub_docs` 字段
